## 独立性能复测

结果来自 `outputs/benchmark-isolated/benchmarks.json`，该复测期间没有并行运行模型训练。当前训练集规模为 166464 条交互，额外评估 50K / 200K / 1M。每项先预热一次、正式测量三次，报告中位数。下表是 1M 交互、7563 个序列块、五折 OOF 的结果：

| 后端 | 线程数 | 中位耗时（ms） | 相对 Python 加速比 | 最大绝对误差 |
| --- | ---: | ---: | ---: | ---: |
| Python 参考实现 | 1 | 14281.440 | 1.00 | 0 |
| C++17 | 1 | 239.341 | 59.67 | 0 |
| C++17 | 2 | 149.097 | 95.79 | 0 |
| C++17 | 4 | 106.345 | 134.29 | 0 |
| C++17 | 8 | 118.156 | 120.87 | 0 |

计时包含 OOF 拟合、特征提取、输出分配、折检查和线程启动，不含数据下载、CSV 读取、预打包或神经网络训练。Python 与 C++ 使用相同的计数差分算法；速度比较针对当前可读 Python 参考实现，不能外推为相对所有 Python/NumPy/Numba 实现的加速幅度。8 线程在本次中位数上慢于 4 线程，保留实测结果。
